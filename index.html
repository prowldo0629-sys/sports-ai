Gemini 연결

현재 화면이 분석을 위해 Google Gemini로 전송돼요. 앱은 영상을 따로 저장하지 않아요. 실시간 중계는 분석 시간 때문에 몇 초 늦을 수 있어요. 지연 없이 보여 주려면 영상 파일로 「미리 생성 중계」를 쓰세요.

Claude 화면에서는 키 없이 「미리 생성 중계」를 Claude가 만들 수 있어요. 실시간 중계와 웹캠은 HTML 파일을 내려받아 크롬에서 Gemini 키로 써 주세요.
